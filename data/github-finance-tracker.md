# AI Finance Tracker

## Repository

https://github.com/Codewizkashish/ai-finance-tracker

## Project Summary

AI Finance Tracker is a full-stack personal finance management platform that automates expense categorization and financial tracking using AI. The system reduces manual bookkeeping effort by intelligently classifying transactions and providing users with structured financial insights.

## Problem It Solves

Traditional expense trackers require users to manually enter and categorize expenses, making long-term usage tedious. This project automates categorization and analysis to improve user experience and financial visibility.

## Biggest Technical Challenge

Running LLM-based categorization on every transaction introduced latency and increased inference costs.

## Solution

Implemented vendor-based caching and rule-based classification for common transactions, invoking AI only for ambiguous cases.

## Project Summary

An AI-enabled platform for tracking, visualizing, and managing assets across geographic and spatial environments.

## Problem It Solves

Organizations struggle to manage assets across large facilities and geographically distributed locations.

* TypeScript
* FastAPI
* PostGIS
* Neo4j
* Supabase

Maintaining synchronization between spatial visualizations and backend asset state.

## Solution

Separated geometry rendering workflows from metadata update operations through optimized state management.

# Weather App

https://github.com/Codewizkashish/Weather-App

## Project Summary

A weather forecasting application providing current weather conditions, hourly forecasts, and daily forecasts with customizable themes and measurement units.

## Tech Stack

* React
* JavaScript
* Weather APIs

## Features

* Current weather conditions.
* Hourly forecasts.
* Daily forecasts.
* Dark mode and light mode.
* System theme synchronization.
* Unit conversion support.

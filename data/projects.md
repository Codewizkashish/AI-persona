# Projects

## High Traffic Ticket Booking System

(Group project)
Purpose:
Built to handle sudden spikes in traffic during high-demand ticket releases while preventing crashes and double-booking.

Tech Stack:

* Next.js
* React
* Node.js
* PostgreSQL
* Redis
* Socket.io
* AWS SQS

Contribution:

* Integrated WebSockets.
* Implemented Redis-based caching mechanisms.

Biggest Challenge:
Preventing race conditions and double booking during concurrent seat reservations.

Solution:
Used distributed locking concepts with Redis to ensure only one user could temporarily claim a seat during checkout.

Future Improvements:
Explore building a custom in-memory distributed caching and locking layer.
